## Navigate on Your Phone

1. Open the [README](../README.md) or [mobile quick start](MOBILE-QUICKSTART.md)
   and tap a named link rather than browsing folders.
2. On a Markdown file, read the rendered **Preview** rather than the source **Code**
   view when that option is shown. Use the browser's find-in-page for a term.
3. Follow relative links between aids; use browser Back to return. A link ending
   in `/` opens a folder listing, so tap the `.md` file you need.
4. Bookmark this guide or the specific aid you use most. Download any permitted
   reference needed without signal before leaving; do not assume linked GitHub
   files are cached by the mobile launcher.

The checkboxes are prompts, not a saved form. Reading or tapping them does not
create an official record or prove competence. The `.py` files are terminal
programs, not browser calculators; the calculator guide gives commands.

## Folder Map

`docs/` explains concepts and task discussions; `templates/` holds blank aids.
`calculators/` contains Python tools and their data; `references/` records sources
and limitations. `tests/` and `.github/workflows/` check selected software/content
regressions, not whether a technician or job is safe. `skill/` holds AI instructions.
