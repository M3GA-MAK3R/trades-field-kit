# Refrigerant and Safety Reference Audit

This update corrects the remaining supported refrigerant tables and removes
selected unsafe shortcuts from the field references. It is not an engineering
approval, regulatory compliance assessment, or certification of the entire kit.
The [README](../README.md) remains short; operational detail belongs in the
[safety boundaries](../docs/SAFETY.md) and [calculator guide](../calculators/README.md).

## Refrigerant Corrections

- **R22:** Replaced the two separate legacy tables with one shared table based on
  the R22 column of [Honeywell G525-093 (2011)](https://prod-edam.honeywell.com/content/dam/honeywell-edam/pmt/oneam/en-us/refrigerants/documents/pmt-am-genetron-aZ20-genetronr22-pressure-temp-chart-tech-tool1.pdf).
  The implementation uses exact source entries at 5°F intervals, inverted to
  pressure keys, and interpolates only inside 0.6–381.7 PSIG.
- **R134A:** Replaced the separate legacy tables with Appendix E, Genetron 134a,
  of [Honeywell 1950 FP Ref v7 (December 2017)](https://prod-edam.honeywell.com/content/dam/honeywell-edam/pmt/oneam/en-us/refrigerants/documents/pmt-am-solstice-n13-commercial-refrigeration-retrofit-tech-guide1.pdf).
  The range is 0–280 PSIG, with linear interpolation between the published points.
  For example, the old subcooling table used 99°F at 150 PSIG; the manufacturer
  value is 111.5°F, a 12.5°F saturation-temperature error.
- **Shared behavior:** All three supported refrigerants use the same source table
  for both calculations, with finite-input checks, bounded interpolation, and
  source attribution in CLI output. R32/R454B and vacuum pressure inputs remain
  unsupported. Table bounds are not equipment operating limits.

## Safety Corrections

- **Stored energy:** Removed universal resistor/wait-time directions and improvised
  terminal-shorting instructions. References now defer to equipment-specific
  discharge and verification procedures with approved rated tools. Hazardous
  stored electrical energy must be controlled; associated equipment is treated
  as energized during the discharge work
  ([OSHA 1910.333(b)](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.333)).
- **Energy-control scope:** Replaced generic LOTO sequences with discussion prompts
  that address stored energy, reaccumulation, authorization, group/shift continuity,
  and approved return to service. Electrical exposure is not governed solely by
  the machine-servicing standard
  ([OSHA 1910.147](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.147),
  [1910.333](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.333)).
- **Instruments and PPE:** Removed blanket meter-category, glove-class, and capacitor
  tolerance claims. Instrument and protective-equipment suitability depends on the
  actual circuit, environment, task, and hazards
  ([OSHA 1910.334](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.334),
  [1910.335](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.335)).
- **Coil cleaning:** Removed the generic pressure limit, nozzle distance, spray angle,
  and fin-tool recipe. Some equipment prohibits pressure washers, chemicals, or
  hard-tool contact, so the actual coil instructions must govern
  ([Johnson Controls TMAL bulletin TPM-SI0245](https://docs.johnsoncontrols.com/ductedsystems/api/khub/documents/TUg78wHItRmyi4kpDTod4w/content)).
- **Diagnostics and qualifications:** Removed generic normal-charge targets and
  deterministic pressure-pattern diagnoses. Refrigerant-work guidance refers to
  task-specific Section 608 requirements and conditions for apprentice exceptions
  ([EPA requirements](https://www.epa.gov/section608/section-608-technician-certification-requirements),
  [EPA technician Q&A](https://www.epa.gov/section608/epas-refrigerant-management-program-questions-and-answers-section-608-certified)).
- **Propagation:** Updated Markdown references, the printable PDF and generator,
  both AI-skill copies, and public issue warnings. The PM page links to the
  individual task aids instead of maintaining conflicting duplicated procedures.
  No installed personal skill or website application code is changed.

## Verification and Limits

The automated suite checks manufacturer anchor values for all supported
refrigerants, shared tables, monotonicity, interpolation, boundaries, CLI output,
failure exits, selected safety phrases, skill-copy parity, local documentation
links, and the slim README. Content checks are regression guards, not a safety
review by a qualified professional. PDF checks additionally require regeneration,
text inspection, structural validation, and visual inspection of all four pages.

Local verification completed with 30 passing tests on Python 3.12 and 3.14,
matching skill copies, a successful skill-format validation, valid YAML and shell
syntax, resolving local Markdown links, and a 36-line README. The regenerated
four-page PDF passed structural/text/bounds checks and visual inspection.

The audit does not validate every wiring diagram, electrical-sizing example,
motor-current estimate, airflow model, heat-pump sequence, combustion task,
jurisdiction, or equipment procedure. Those references remain educational and
need model-specific verification. The phone interface's offline behavior and
interactive calculators are a separate unfinished workstream.

Do not extend the refrigerant list or reinstate generic safety instructions
without a traceable source, explicit limits, and regression tests. Before any
operational reliance, obtain qualified review of the applicable equipment
instructions and employer procedures; this kit is never that approval.
